## 🚀 Featured Projects

### [CLO](https://github.com/Guilherme-Jenner/CLO) — Fashion Social App
Cross-platform fashion app with social network, virtual try-on, wardrobe manager and outfit planner — built end-to-end and shipped to the **App Store**.

- **Back-end:** .NET 8 · Clean Architecture · EF Core · SignalR · Hangfire (EDA) · JWT · Cloudinary
- **Front-end:** Angular 17+ (Signals, Standalone) · Ionic · Capacitor · Angular CDK
- **Highlight:** Interactive outfit canvas with Free Dragging — persisting X/Y coordinates and Z-index layer hierarchy per item in the database
- **Result:** 500+ real users · 90% onboarding completion rate from day one
